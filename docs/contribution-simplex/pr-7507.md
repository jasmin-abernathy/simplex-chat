android: allow disabling the proximity sensor during calls

Addresses #7507.

Add an Android-only “Disable proximity sensor during calls” setting under Audio & video calls. It defaults to off, preserving the existing proximity behavior. The preference is stored locally and updates the call view reactively. English and French strings are included.

When enabled, the call view does not acquire the proximity screen-off wake lock. The existing call activity screen-on flags remain responsible for keeping the visible call screen awake. Manual screen locking is unaffected.

The proximity effect releases its lock on cancellation, including collapse and disposal. Lock updates and close are synchronized, and a closed call cannot acquire the lock after the one-second delay.

No APK or device testing is available yet. Hardware proximity behavior, Bluetooth, PiP, lock-screen and accessibility checks remain pending. The setting is not included in settings export/import.
